# OpenFGA Authorization Model

Минимальная модель авторизации OpenFGA (ReBAC) для организационной структуры компании: подразделения, штатное расписание, сотрудники, замещения, роли и таблица ручных исключений/грантов.

Проект полностью работает на **Node.js** (без Python и без внешних npm-зависимостей).

---

## Быстрый старт

### 1. Запуск OpenFGA (in-memory)
```bash
docker compose up -d
```

### 2. Запуск приложения и веб-интерфейса
```bash
npm start
```
Откройте в браузере: **[http://localhost:3000](http://localhost:3000)**
- **⚡ Быстрые пресеты в 1 клик**: готовые сценарии проверок и выборок для всех 7 типов (Сотрудники, Подразделения, Роли, Профессии, Штатка, Гранты).
- **🔍 Поиск всех зависимостей**: интерактивный выбор любого типа сущности и получение любых связанных объектов (роли, иерархия отделов вверх/вниз, штатки, замещения) + точечный Check.
- **📊 Таблицы данных**: просмотр и фильтрация всех 7 CSV-таблиц.

---

## Команды

| Команда | Описание |
|---|---|
| `npm run dev` | Запуск сервера в режиме разработки с автоперезагрузкой (`--watch`) |
| `npm start` | Запустить локальный веб-сервер на порту 3000 |
| `npm test` | Запустить автотесты проверок доступа (`node:test`) |
| `npm run import` | Перезагрузить модель `model.fga` и данные из папки `csv/` в OpenFGA |

## Структура проекта

```text
├── model.fga          # Модель авторизации OpenFGA (схема 1.1)
├── csv/               # 7 реляционных CSV таблиц (divisions, professions, staffs, ...)
├── public/            # Веб-интерфейс (index.html)
├── src/
│   ├── client.js      # Минимальный OpenFGA клиент (check, listObjects, listUsers)
│   ├── import.js      # Синхронизация CSV в кортежи OpenFGA
│   └── server.js      # Нативный HTTP-сервер Node.js (порт 3000)
├── test/
│   └── test.js        # Тесты проверок доступа
├── docker-compose.yml # Запуск OpenFGA в Docker
└── package.json
```
